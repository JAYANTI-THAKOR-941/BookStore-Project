# Bookstore Management

Node.js bookstore project with book and user models, routes and EJS views for adding, editing and browsing books.

## Project structure

`controllers/`, `models/`, `routes/`, `views/`, `config/db.js`, `index.js`

## Getting started

```bash
git clone https://github.com/JAYANTI-THAKOR-941/BookStore-Project.git
cd BookStore-Project
```

Run `npm ci`, configure the database locally and inspect the package scripts or launch `node index.js`.

## Security configuration

An environment file is currently tracked. Treat any real credentials in it as potentially exposed, rotate them, and migrate secrets to ignored local environment files. Do not publish secret values.
